# Europe Order Bot

Telegram-бот для предварительного расчёта заказов.

## Railway
1. Создайте сервис из GitHub-репозитория.
2. Добавьте переменную `BOT_TOKEN` с **новым** токеном от BotFather.
3. Start Command: `python bot.py`. Публичный домен не требуется.
4. Запускайте только один экземпляр бота.

## Логика тестовой версии
- Курс 114 ₽ за евро.
- Доставка 27 € за посылку.
- Пошлина 13% на сумму превышения 200 € в каждой посылке.
- Не более 299 € и 10 товаров в одной посылке.
- Внутренняя доставка 4 € за заказ. **В этой версии условно считается один внутренний заказ на посылку.** Если объединять несколько заказов в одну посылку, нужно отдельно учитывать их число. Пока не использовать расчёт как окончательный счёт клиенту.
- Алгоритм упаковки не гарантирует минимальную итоговую стоимость.

Пример сообщения боту:
```
45 2
89
120
```
